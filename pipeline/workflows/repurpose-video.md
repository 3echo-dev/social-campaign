# Workflow: repurpose-video (v1.0.0)

Kinds: `content_repurpose`.
Same condition syntax and column meanings as `organic-post.md`. The source video is watched and analysed before anything is planned. Claims spoken in the source are usable only when a transcript exists.

| # | Stage | Task | Condition | Agent | Role | Owner | Skills | Artifact | State after | Gate |
